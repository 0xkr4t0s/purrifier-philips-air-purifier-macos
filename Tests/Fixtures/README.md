Notes on the AC0850/11 dumps:

- The issue labels two dumps "Mode Turbo". The second has `D0310C: 0` and `D0310D: 1`, which is Auto; it is stored as `auto.json`.
- "Mode Off (Auto)" means power off (`D03102: 0`) with Auto as the last mode.
- `DeviceId`/`ProductId` are as published in the public issue.
